# 数据写入与结构修改

对照 dev 的 Java Chen，Go/Luna 工作区接入了表格增删改、选中行批量赋值、CSV 导入草稿、建表、字段及索引修改，以及 SQL 文件载入。浏览器仍只使用 HTTP 与每会话一条 SSE；没有为写入新增 WebSocket。

## 操作流程

- 从对象树打开表数据，可新增、删除、修改行；单表直接投影的查询结果可修改字段。单元格 F2 打开编辑，双击保留大字段查看。修改保留在草稿中，点击保存后先预览 SQL，再确认提交。
- NULL、空字符串和新增行的 DEFAULT 分开表示。批量修改只作用于选择的行。未保存时阻止翻页、换结果、导出和丢弃工作区，避免保存到错误快照。
- 保存成功后刷新数据，重新取得可信行标识；并发冲突、结构变化、计划过期均要求重新载入。连接中断且数据库结果不明时显示 unknown，不自动重试。
- CSV 先解析、映射列并形成草稿，与普通网格共用预览和保存。文件上限 10 MiB、每次最多 500 条变更，并校验 2 MiB 提交预算；不会把大文件悄悄拆成多个可能部分成功的事务。SQL 文件上限 1 MiB，按 UTF-8 载入新编辑器，不直接执行。两者在托管模式均受 Core upload 权限控制；single 模式由本地配置账号权限决定。
- 对象树提供建表、修改字段、创建/删除索引入口，先生成可审阅 SQL，确认后走普通执行路径。对于可能丢失默认值、注释、生成属性的字段修改，不生成不完整的替换定义；提供完整 DDL 进入编辑器核对。主键、唯一及约束索引不提供快捷删除，需检查完整 DDL 后手动处理。结构修改及普通脚本不承诺整批事务回滚，数据库可能隐式提交 DDL。

## 网格可编辑条件

需要真实基础表、单列主键和可确认来源的直接投影。主键、生成列、自增列、已脱敏字段不可直接修改；新增行可省略生成列以采用数据库默认值。主键原值保留在服务器，浏览器只提交不透明 row_ref。

JOIN、CTE、表达式、聚合、DISTINCT、多个结果集、视图、无主键或复合主键结果保持只读，并显示原因。这些限制与旧版的单表/单列主键设计一致。二进制、数组、空间类型、用户自定义类型及需要驱动专门处理的 LOB 暂不提供网格赋值，仍可查看或通过 SQL 修改。ClickHouse 不提供事务网格保存，可通过 SQL 执行其支持的写入和结构操作。

MySQL/MariaDB/OceanBase MySQL 网格只接受 InnoDB 基础表，避免非事务表产生半批提交。Oracle 空字符串按数据库语义成为 NULL。精确整数和小数从浏览器到驱动保持字符串，不经 JavaScript number。

## 服务端提交与审计

服务器根据固定的结果来源、真实列元数据和原始值生成参数化写入计划，不接受客户端 SQL、WHERE 或主键作为执行依据。计划默认 15 分钟有效，同一计划不能重复落库；相同 request_id 仅返回同一个执行。每次最多 500 条变更，SQL 预览上限 2 MiB。

整批及每条 SQL 在开始写入前均做 Core ACL、告警确认及工单复核。审批绑定不可变计划；待审期间暂停、关闭、拒绝或取消均不会写入。执行前记录意图，执行后记录提交、暂存、回滚或未知状态；审计投递失败不会把已提交数据库操作误报成已回滚。

空闲的自动提交连接使用独立事务；已处于可识别用户事务时使用保存点，保存成功仅显示“已暂存”，不会提交外层事务。无法可靠识别的事务状态拒绝网格保存。更新用主键及被修改字段的原始值检测冲突，删除检查可比较的原始字段；任一操作影响行数不等于 1 时整批回滚。未参与比较的字段发生变化不一定被检测到，这不是全表版本锁。

普通 SQL 使用各方言解析器或保守语句边界检查。扩展方言支持常见 CRUD、TABLE/INDEX/VIEW DDL 和事务语句；过程体、客户端 GO/DELIMITER、含糊的无分号批处理和权限管理语句可能被明确拒绝。扫描器不是完整厂商 AST，数据库仍负责最终语法与权限校验。

## 验证入口

写测试必须独立显式开启；只读矩阵变量不会触发写操作。测试只创建唯一的 CHEN_W_/CHEN_E_/CHEN_M_ 表，并清理自己创建的准确表名，不修改业务表。

```sh
go test -race ./...
CHEN_WRITE_BACKENDS=/private/backends.yml go test ./internal/engine -run 'Test(WriteCommands|GridEdits)Live' -count=1 -v
CHEN_WRITE_MANAGED=1 CHEN_MANAGED_FIXTURE=/private/fixture.json go test ./internal/engine -run '^TestGridEditsManagedLive$' -count=1 -v
```

Db2 实库测试需要 IBM CLI 和 `-tags ibmdb`，见[构建说明](build.md)。Core/Wisp 写入验收使用隔离本机环境，包含拒绝、待审无写入、批准、告警确认、暂停取消、上传权限、真实 Core 命令审计和会话录像。
